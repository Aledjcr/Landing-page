Sobre mí

Soluciones simples para problemas complejos

Soy desarrollador de software y disfruto transformar ideas en experiencias digitales funcionales. Trabajo con una mirada integral: arquitectura, interfaz, rendimiento y facilidad de mantenimiento.

Mi enfoque combina código limpio, decisiones de diseño centradas en el usuario y aprendizaje continuo. Cada proyecto es una oportunidad para reducir fricción, automatizar tareas y construir una base sólida para evolucionar.

Calidad técnica

Estructuras semánticas, código legible y componentes fáciles de extender.

Experiencia de usuario

Mejora continua

Iteración basada en resultados, rendimiento y necesidades reales.
